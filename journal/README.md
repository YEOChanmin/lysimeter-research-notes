## Writing the next entry

Use the [research-note template](../templates/research-note.md). Record the question, change, evidence, limitations and next question, then link the entry from this index and the home page.

Keep literature citations distinct from field records. Cite actual source locations for paper-based claims. Corrections should include their date and reason. Do not paste private paths, operational addresses, credentials or authorization records into a public entry.
